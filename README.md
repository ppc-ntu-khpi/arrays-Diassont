# Практична робота - Перевірка числа Армстронга 
Цей проект містить реалізацію алгоритму для перевірки, чи є задане число числом Армстронга.

----

## Завдання, яке було обрано:
Перевірте чи є задане число [числом Армстронга](https://uk.wikipedia.org/wiki/%D0%A7%D0%B8%D1%81%D0%BB%D0%B0_%D0%90%D1%80%D0%BC%D1%81%D1%82%D1%80%D0%BE%D0%BD%D0%B3%D0%B0)

----

## Опис завдання

Число Армстронга — це число, яке дорівнює сумі своїх цифр, кожна з яких піднесена до степеня, що дорівнює кількості цифр у числі. Наприклад, 153 є числом Армстронга, тому що \(1<sup>3</sup> + 5<sup>3</sup> + 3<sup>3</sup> = 153\).

----

## Що було виконано в рамках практичної роботи

1. **Метод `Calculate` класу `Exercise` був модифікований**:  
   Реалізовано перевірку, чи є задане число числом Армстронга. Алгоритм визначає кількість цифр у числі, підносить кожну цифру до відповідного степеня і обчислює суму. Порівнюючи результат із початковим числом, визначається, чи є воно числом Армстронга.

2. **Клас `TestResult` був оновлений**:  
   Змінено повідомлення, яке виводиться у методі `main`. Тепер виводиться результат перевірки у форматі:  
   `Число 153 є числом Армстронга.` або `Число 154 не є числом Армстронга.`
   
3. **Враховано вимоги до якості коду**:
   - ✅ Обрано оптимальні типи даних (`int`, `boolean`) відповідно до задачі.
   - ✅ Іменування змінних відповідає Java-конвенціям (`original`, `sum`, `digit`, `number` тощо).
   - ✅ Додано **Javadoc-коментарі** до класу `Exercise` та методу `Calculate`, які пояснюють суть обчислення та очікувані вхідні параметри.
